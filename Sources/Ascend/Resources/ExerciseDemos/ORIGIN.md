# Generated workout artwork

Created for Ascend with the built-in image-generation tool, 4 November 2026.
No personal photographs, measurements, profile information or private exercise
weights were supplied. Subjects are fictional, anonymous athletic figures.

The PNGs preserve actual transparent alpha. The incline-press cutout received a
second background-removal pass using the same image tool. ffmpeg downscaled the
assets and made 3-second transparent GIFs with a gentle whole-image vertical float.
The pose never changes: this is decorative motion, not a rep or a form lesson.
Motion is opt-in; static PNG is the default. No old GymMane SVG poses are included.
